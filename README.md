# Yuvraj Jakhar — Digital Marketing Portfolio

V2 premium React/Vite portfolio with project filters, case-study modals, responsive layout, and three lightweight working video previews.

## Run
1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

## Video previews
V2 already includes three compressed MP4 previews in `public/videos/`. Replace them with your strongest edits if you want a more polished final reel selection. The originals are not bundled because they are much larger.

Suggested filenames:
- uddan-reel-1.mp4
- uddan-reel-2.mp4
- vama-reel-1.mp4
- get-viral-news-1.mp4

The starter intentionally does NOT bundle the large raw MP4 files to keep the project lightweight.

No Meta Ads performance numbers are invented. The Paid Media section is positioned as capability/approach until you have permissioned campaign data.
